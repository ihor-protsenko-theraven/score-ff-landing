# ЧУФФ-Мікс 2026 — FLAG SCORE

Live-center чемпіонату України зі змішаного флаг-футболу. Публічна сторінка показує рахунки наживо, розклад і автоматично розраховану турнірну таблицю. Через захищену адмін-панель організатори можуть оновлювати команди, матчі, результати та інформацію про турнір без редагування коду.

Production: [score-ff-landing.vercel.app](https://score-ff-landing.vercel.app/)

## Турнір

- Дати: 12–13 вересня 2026 року.
- Початок матчів: 12 вересня об 11:00, 13 вересня о 09:00.
- Локація: стадіон Житомирського обласного ліцею Житомирської обласної ради, вул. Коростишівська, 15, Житомир — [відкрити на Google Maps](https://maps.app.goo.gl/SdcT7nBRSaUqjQb68).
- Учасники: Бізони, Вовки, Збірна Ю15, Леви, Лісоруби та Орли.
- Розклад: буде внесено через адмін-панель після публікації сітки організаторами.

### Доповнення до регламенту

1. На полі мають одночасно перебувати щонайменше дві дівчини. Для «Бізонів» допускається одна; суперник у матчі проти «Бізонів» також може грати з однією дівчиною.
2. Під час повітряної тривоги матч зупиняється, поле звільняється, а учасники прямують в укриття. Фіксуються рахунок, спроба, час до завершення, команда у володінні та напрямок атаки. Якщо тривога триває понад 30 хвилин, остаточним вважається рахунок на момент її оголошення.

Орієнтовна вартість нагородження — 10 000 грн, розподілена між усіма командами. Вартість суддівства залежить від кількості команд, матчів і доступних суддів; розрахунок із головним суддею проводиться готівкою. Заявку у форматі Word потрібно було подати до вечора 4 вересня 2026 року, а оригінал — привезти на змагання.

## Можливості

- live-рахунки та статуси матчів: заплановано, наживо, перерва, завершено;
- розклад у вигляді списку або з групуванням за полями;
- автоматичні турнірні таблиці за результатами завершених матчів;
- українська й англійська версії публічного інтерфейсу;
- захищене керування турніром через `/admin`;
- автоматичне оновлення публічної сторінки кожні 10 секунд;
- постійне збереження продакшн-даних у приватному Vercel Blob.

## Локальний запуск

Потрібен Node.js 20 або новіший.

```powershell
npm install
$env:ADMIN_PASSWORD="надійний-пароль"
npm start
```

Після запуску відкрийте:

- публічну сторінку — `http://localhost:3000/`;
- адмін-панель — `http://localhost:3000/admin`.

Локально зміни з адмін-панелі записуються у `data/tournament.json`. Якщо `ADMIN_PASSWORD` не задано, використовується лише локальний демо-пароль `flag2026`.

## Змінні середовища

Приклад наведено у `.env.example`.

| Змінна | Обов'язкова | Призначення |
| --- | --- | --- |
| `ADMIN_PASSWORD` | у production | Пароль входу та запису через адмін-панель. |
| `BLOB_READ_WRITE_TOKEN` | у production | Токен приватного Vercel Blob для постійного збереження даних. |
| `PORT` | ні | Локальний порт, стандартно `3000`. |
| `DATA_FILE` | ні | Локальний шлях до JSON-файлу турніру. |

Без `BLOB_READ_WRITE_TOKEN` Vercel показує вбудований набір даних у режимі читання. Для збереження змін з адмін-панелі підключіть приватний Blob store до проєкту. Без `ADMIN_PASSWORD` production-адмінка повертає помилку конфігурації замість використання демо-пароля.

## Деплой на Vercel

1. Встановіть і запустіть Vercel CLI: `npx vercel@latest`.
2. Прив'яжіть або створіть Vercel-проєкт для цього репозиторію.
3. Створіть приватний Blob store у розділі **Storage** проєкту та підключіть його до production, щоб Vercel автоматично додав `BLOB_READ_WRITE_TOKEN`.
4. Додайте `ADMIN_PASSWORD` до змінних середовища production.
5. Виконайте `npx vercel@latest --prod`.

Файли з `public/` віддаються через CDN, а маршрути `api/` працюють як Vercel Functions. Початкові дані зберігаються в `data/tournament.json`; попередній демо-турнір залишено в `tournament-archive-kyiv-flag-football-cup-2026.json`.
